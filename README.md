# Sipariş Yönetim Sistemi

Bu proje, YZM202 Yazılım Yapılandırma dersi kapsamında geliştirilmiştir.

## Proje Amacı

Müşteri, ürün, sipariş ve kargo işlemlerini yönetebilen modüler bir sipariş sistemi geliştirmektir.

## Kullanılan Teknolojiler

- Python
- Pytest
- Coverage
- Git

## Proje Özellikleri

- Müşteri oluşturma
- Ürün oluşturma
- Sipariş oluşturma
- Siparişe ürün ekleme
- Toplam tutar hesaplama
- Kargo durumu güncelleme
- Sipariş iptal sistemi
- Unit Test
- Integration Test
- System Test
- Coverage raporu
